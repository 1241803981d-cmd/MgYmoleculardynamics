# Data

This directory contains the numerical source data and representative
configurations distributed with the study. See:

- `../docs/DATA_DICTIONARY.md` for variables and units.
- `../docs/FIGURE_MAP.md` for exact figure mapping.
- `../MANIFEST.tsv` for file sizes and SHA-256 checksums.

The files `MgY_2at_initial.lmp` and `model_MgY_grains.lmp` are representative
configurations, not full trajectories. Complete trajectories are described in
`../raw_trajectories/README.md`.
